# 测试策略文档

## 文档信息
- **文档版本**: v1.0
- **创建日期**: 2026-03-15
- **测试负责人**: QA Engineer
- **适用范围**: 批量回测功能 V1.0

---

## 一、测试目标

### 1.1 总体目标
确保批量回测功能在 V1.0 版本中满足功能需求、性能要求和可靠性标准。

### 1.2 具体目标
- 验证批量回测核心功能正确性
- 验证状态流转逻辑正确性
- 验证与现有功能的兼容性
- 建立性能基准数据

---

## 二、测试范围

### 2.1 In Scope

| 模块 | 测试内容 |
|------|----------|
| 批量任务创建 | 参数验证、交易对获取、任务初始化 |
| 批量任务执行 | 串行执行、进度更新、结果保存 |
| 任务控制 | 暂停、继续、取消、重试 |
| 进度跟踪 | 进度计算、状态查询、预估时间 |
| 结果查询 | 汇总统计、详情列表、排序筛选 |
| 启动恢复 | 任务恢复、状态重建 |
| 兼容性 | 与现有单回测功能共存 |

### 2.2 Out of Scope

| 模块 | 说明 |
|------|------|
| 前端界面测试 | 由前端团队负责 |
| 并行执行 | V2.0 功能 |
| 分布式执行 | V2.0+ 功能 |
| 可视化图表 | 复用现有功能 |

## 三、测试策略

### 3.1 测试金字塔

```
         /\
        /  \     E2E 测试 (10%)
       /----\    - 完整业务流程
      /      \   - 关键用户场景
     /--------\
    /          \  集成测试 (30%)
   /------------\ - API 接口集成
  /              \ - 数据库集成
 /----------------\
/                  \ 单元测试 (60%)
/--------------------\ - 业务逻辑
                       - 状态流转
```

### 3.2 测试分层策略

| 层级 | 覆盖率目标 | 自动化 | 工具 |
|------|------------|--------|------|
| 单元测试 | 80%+ | 必须 | Jest |
| 集成测试 | 70%+ | 必须 | Jest + Supertest |
| E2E 测试 | 核心流程 | 建议 | 手动/自动化 |

### 3.3 测试类型分配

| 测试类型 | 占比 | 重点 |
|----------|------|------|
| 功能测试 | 50% | 核心功能、状态流转 |
| 边界测试 | 20% | 空值、极限值、异常输入 |
| 性能测试 | 15% | 响应时间、执行效率 |
| 兼容性测试 | 10% | 与现有功能共存 |
| 恢复测试 | 5% | 启动恢复、故障恢复 |

```yaml

  stages:
    - unit_test:
        script: npm run test:unit
        coverage: 80%
    - integration_test:
        script: npm run test:integration
        needs: [unit_test]
    - e2e_test:
        script: npm run test:e2e
        needs: [integration_test]
```

## 七、风险与缓解

### 7.1 测试风险

| 风险 | 等级 | 缓解措施 |
|------|------|----------|
| 测试数据准备不足 | 中 | 提前准备标准化测试数据集 |
| 执行时间测试成本高 | 中 | 使用少量交易对进行功能验证 |
| 状态恢复测试复杂 | 高 | 设计专门的恢复测试用例 |
| 并发场景难以模拟 | 中 | 使用自动化工具模拟并发 |

### 7.2 质量风险

| 风险 | 等级 | 缓解措施 |
|------|------|----------|
| 状态不一致 | 高 | 加强状态流转测试 |
| 性能不达标 | 中 | 早期性能基准测试 |
| 兼容性问题 | 中 | 充分回归测试 |

## 八、验收标准

### 8.1 功能验收

- [ ] 所有 P0 测试用例通过
- [ ] 所有 P1 测试用例通过 90%+
- [ ] 无 P0/P1 级别 Bug

### 8.2 质量指标

| 指标 | 目标值 |
|------|--------|
| 单元测试覆盖率 | >= 80% |
| 集成测试覆盖率 | >= 70% |
| 缺陷密度 | < 0.5 个/功能点 |
| 严重缺陷率 | 0% |

### 8.3 性能指标

| 指标 | 目标值 |
|------|--------|
| 创建任务 API | < 500ms |
| 查询任务 API | < 200ms |
| 批量执行效率 | < 120% * 单回测耗时 * 数量 |
