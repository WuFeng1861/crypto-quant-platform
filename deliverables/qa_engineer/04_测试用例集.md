## 一、批量任务创建测试

### TC-01-001: 创建批量任务-全部交易对
- **前置条件**: 系统存在交易对数据（如 8000 个）
- **输入**:
  ```json
  {
    "strategyId": 1,
    "timeframeId": 1,
    "startTime": "2024-01-01T00:00:00.000Z",
    "endTime": "2024-12-31T23:59:59.000Z",
    "initialCapital": 10000
  }
  ```
- **执行步骤**:
  1. 调用 POST /backtest/batch
  2. 不传 pairIds 参数
- **预期结果**:
  1. 返回 201 Created
  2. 返回 batchId
  3. totalPairs 等于系统中所有交易对数量（不超过 10000）
  4. status 为 "queued"（进入队列等待执行）
- **优先级**: P0
- **关联需求**: PRD-4.1, PRD-4.5
