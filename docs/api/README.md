# 量化回测平台 API 文档

本文档目录包含了量化回测平台的完整API接口文档，按模块分类组织。

## 文档结构

- [API 响应格式](./response-format.md) - 统一的API响应格式说明
- [价格数据管理 API](./price-data.md) - 价格数据、交易对、时间框架管理
- [指标管理 API](./indicators.md) - 技术指标的创建、查询和计算
- [策略管理 API](./strategies.md) - 交易策略的创建和管理
- [回测系统 API](./backtest.md) - 策略回测执行和结果查询
- [使用示例](./examples.md) - 完整的API使用示例和集成代码

## 快速开始

1. 首先阅读 [API 响应格式](./response-format.md) 了解统一的响应格式
2. 根据需要查看对应模块的API文档
3. 参考 [使用示例](./examples.md) 进行实际集成
