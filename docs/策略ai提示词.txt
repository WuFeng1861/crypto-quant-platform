【指标生成要求】
  【指标函数参考】
  function calculate(priceData, parameters) { const period = parameters.period || 14; const result = []; let gains = new BigNumber(0); /* 使用 BigNumber 存储累计涨幅 */ let losses = new BigNumber(0); /* 使用 BigNumber 存储累计跌幅 */ for (let i = 0; i < priceData.length; i++) { if (i === 0) { result.push(null); continue; } /* 计算价格变化 */ const currentPrice = new BigNumber(priceData[i].closePrice); const prevPrice = new BigNumber(priceData[i - 1].closePrice); const change = currentPrice.minus(prevPrice); if (i < period) { /* 累计前 period 个周期的涨跌幅 */ if (change.isGreaterThanOrEqualTo(0)) { gains = gains.plus(change); } else { losses = losses.plus(change.abs()); } if (i === period - 1) { /* 计算初始 RSI */ const avgGain = gains.dividedBy(period); const avgLoss = losses.dividedBy(period); let rsi; if (avgLoss.isZero()) { rsi = new BigNumber(100); } else { const rs = avgGain.dividedBy(avgLoss); rsi = new BigNumber(100).minus(new BigNumber(100).dividedBy(rs.plus(1))); } result.push(rsi.toNumber()); /* 转换为普通数值 */ } else { result.push(null); } } else { /* 使用指数移动平均更新涨跌幅 */ const periodBN = new BigNumber(period); const periodMinus1 = new BigNumber(period - 1); const newGain = change.isGreaterThanOrEqualTo(0) ? change : new BigNumber(0); const newLoss = change.isLessThan(0) ? change.abs() : new BigNumber(0); const avgGain = gains.multipliedBy(periodMinus1).plus(newGain).dividedBy(periodBN); const avgLoss = losses.multipliedBy(periodMinus1).plus(newLoss).dividedBy(periodBN); gains = avgGain; losses = avgLoss; /* 计算 RSI */ let rsi; if (avgLoss.isZero()) { rsi = new BigNumber(100); } else { const rs = avgGain.dividedBy(avgLoss); rsi = new BigNumber(100).minus(new BigNumber(100).dividedBy(rs.plus(1))); } result.push(rsi.toNumber()); /* 转换为普通数值 */ } } return result; }
  【输出格式要求】
  1. 函数签名
  function calculate(priceData, parameters) {
    // 你的代码
  }
  – 参数名必须 priceData、parameters，不得增减。
  – priceData 为数组，元素必含字段：timestamp|openPrice|highPrice|lowPrice|closePrice|volume（未用到可忽略）。
  – 所有浮点运算必须用 BigNumber 完成，禁止出现 + - * / 直接操作 number。
  – 返回结果：
  • 单值指标 → number[] ，长度与 priceData 相同，无数据填 null
  • 多轨指标 → Object[] ，元素为 {key: number|null, ...}

  2. 头部默认值
  - 在函数第一行统一做参数解构与默认值，例如
  const period = parameters.period || 14;
  const stdDev = new BigNumber(parameters.stdDev || 2);

  3. BigNumber 使用规范
  – 全部 new BigNumber(x) 包装后再运算；
  – 比较用 isGreaterThan、isLessThan、isEqualTo、isGreaterThanOrEqualTo、isLessThanOrEqualTo；
  – 除法用 dividedBy，乘法用 multipliedBy，加减用 plus/minus；
  – 返回前用 toNumber() 转回普通数值；
  – 避免除零：若分母可能为 0，先做 isZero() 判断并给出合理默认值（如 50、100、null 等）。

  4. 边界处理
  – 前 N 根数据不足时直接 result.push(null)；
  – 出现 Infinity、NaN 时一律用 null 占位。

  5. 参数设计规则
  – 若用户未指定参数，AI 按经典默认给出；
  – 每个参数须语义化命名：period、stdDev、fastPeriod、slowPeriod、signalPeriod、historyPeriod 等；
  – 凡「周期类」参数一律 number，凡「倍数类」参数一律转成 BigNumber。

  6. 参数信息格式
  除了生成函数代码外，还需要返回参数信息数组，格式如下：
  [
    {
      name: "period",
      description: "计算周期",
      paramType: "number",
      defaultValue: "14"
    },
    {
      name: "stdDev",
      description: "标准差倍数",
      paramType: "number", 
      defaultValue: "2"
    }
  ]

  7. 最终输出格式
  返回一个字符串，包含两个字段，code中绝对不允许存在双斜杠注释（行注释），注释使用块注释：
  {
    "code": "function calculate(priceData, parameters) { ... }",
    "parameters": [...]
  }

【输出格式要求】
1. 根对象字段
name：策略名称，≤30 字，中文优先.名称格式：AI_策略名称
description：策略描述，≤500 字，说明核心逻辑
positionType：仓位类型，双向、做多、做空 枚举值 "both" | "long" | "short"
buyFee / sellFee：手续费，保留 6 位小数，默认 0.001000
liquidationThreshold：强平阈值，保留 2 位小数，默认 90.00
takeProfitRatio / stopLossRatio：止盈/止损比例，可 null，若用户未提及则 null
indicatorNews：新生成指标数组，每个元素必须包含（每一次都生成所需要的指标，存入数据库，这里只需要生成新的指标所需要的数据）
– name: 指标名称，名称格式：AI_策略_指标名称
- description: 指标描述
- code：指标代码
– parameters：指标参数数组，每个元素必须包含，没有参数位空数组
  ‑ value：字符串，用户给定或 AI 按默认
  - name: 参数名必须
  - description: 参数描述,
  - paramType: 参数类型 number|string|boolean,
  - defaultValue: 参数默认值
indicators: 预计算指标数组，可以重复使用同一个指标但是参数不同，有时候也需要比较
- indicatorNewsIndex: 在indicatorNews中的索引
- parameters：指标参数数组，每个元素必须包含，没有参数位空数组
  - value：指标参数值
conditions：数组，每个元素必须包含
– indicatorIndex：指向 indicators 数组下标
– comparisonType：枚举 "constant" | "indicator"
– comparedIndicatorIndex：被比较的指标在indicators中的索引，当 comparisonType="indicator" 时必填，否则省略
– constantValue：被比较的常量，当 comparisonType="constant" 时必填，字符串，保留原始小数位
– currentValuePath / comparedValuePath：若用户无特殊要求，填空字符串
– operator：用于数据比较的方式，枚举 ">" | ">=" | "==" | "!=" | "<" | "<="
– conditionType：枚举 "crossover" | "value"，crossover时operator只能是>或者<,>代表从下往上穿过也就是前一个比较数据是小于等于的，当前数据时大于的，<则是从上往下穿过也就是前一个比较数据是大于等于的，当前数据时小于的，
– action：仓位买入方式做多还是做空。枚举 "buy" | "sell"
– group：≥1 整数，同一 action 下需「同时满足」的条件设同组，「任意满足」设不同组
– priority：组内排序，从 1 开始
– customCode：留空字符串
2. 交叉条件（conditionType="crossover"）
operator 只能 ">" 或 "<"；
">" 表示当前值刚上穿被比较值（前一周期 ≤ 前被比较值，当前 > 被比较值），"<" 反之。
3. 数值精度
所有价格、比例、手续费一律保持用户给定或系统默认小数位，禁止四舍五入。
4. 默认值规则
用户未提及的周期、阈值、手续费等，一律使用【所有指标.txt】里对应参数的 defaultValue；
止盈止损未提及则 null；
positionType 未提及则 "both"。
5. currentValuePath / comparedValuePath 填充规则
 5.1 当「被比较对象」是单个数值（如 RSI、SMA、closePriceRank 等）
  – currentValuePath 留空字符串 ""
  – comparedValuePath 留空字符串 ""
  5.2 当「被比较对象」是复合对象（如布林带返回 {middle,upper,lower}，MACD 返回 {macd,signal,histogram}）
  – 若用户描述里明确提到具体子字段（如“突破上轨”），则
  ‑ currentValuePath 按「当前指标」需要取的子字段填写，例如 "upper"
  ‑ comparedValuePath 按「被比较指标」需要取的子字段填写，例如 "closePrice"（通常当前价格与上轨比，则 currentValuePath 填 "closePrice"，comparedValuePath 填 "upper"）
  – 若用户未明确子字段，则默认取与逻辑最匹配的子字段：
  ‑ 布林带突破上轨 → currentValuePath="closePrice"，comparedValuePath="upper"
  ‑ 布林带突破下轨 → currentValuePath="closePrice"，comparedValuePath="lower"
  ‑ MACD 金叉 → currentValuePath="macd"，comparedValuePath="signal"
  5.3 当 comparisonType="constant" 时
  – comparedValuePath 一律留空字符串 ""
  5.4 所有路径以「点号」分隔嵌套属性，但平台目前只有一层，故直接写子字段名即可，不要带引号，不要带多余层级。
6. 输出格式
仅返回一段合法 JSON，不要注释、不要 markdown 代码块包裹，其余任何文字都不要出现。
