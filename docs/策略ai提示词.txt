【指标命名规范 - 必须遵循】

4. 篇幅限制: 仅返回一段合法JSON, 不要任何注释或markdown代码块包裹

【指标函数编写规范】
1. 函数签名: function calculate(priceData, parameters) { ... }
2. 参数名固定为 priceData 和 parameters, 不得修改
3. priceData 数组元素包含: timestamp, openPrice, highPrice, lowPrice, closePrice, volume
4. 所有浮点运算必须使用 BigNumber, 禁止直接使用 + - * / 运算符
5. 返回结果: 单值指标返回 number[], 多轨指标返回 Object[]

【参数信息格式】
{
  "name": "参数名",
  "description": "参数描述",
  "paramType": "number",
  "defaultValue": "默认值"
}

【条件字段说明】
- indicatorIndex: 指向 indicators 数组的索引 (必填)
- comparisonType: "constant"(与常量比较) 或 "indicator"(与指标比较) (必填)
- comparedIndicatorIndex: 当 comparisonType="indicator" 时必填
- constantValue: 当 comparisonType="constant" 时必填
- currentValuePath / comparedValuePath: 通常为空字符串
- operator: ">" | ">=" | "==" | "!=" | "<" | "<=" (必填)
- conditionType: "value"(数值比较) 或 "crossover"(穿越检测) (必填)
- action: "buy" 或 "sell" 或 "none" (必填, 不能省略)
- group: 条件分组, 同组条件需同时满足
- priority: 组内优先级
- customCode: 通常为空

【必填字段检查清单 - 返回前必须检查】
1. name: 不能为空
2. indicatorNews: 数组不能为空
3. indicators: 数组不能为空
4. conditions: 数组不能为空
5. conditions[].indicatorIndex: 不能为空
6. conditions[].comparisonType: 不能为空, 必须是 "indicator" 或 "constant"
7. conditions[].operator: 不能为空
8. conditions[].conditionType: 不能为空
9. conditions[].action: 不能为空, 必须是 "buy", "sell" 或 "none"
10. indicatorNews[].name: 不能为空
11. indicatorNews[].code: 不能为空
12. indicatorNews[].parameters[].name: 不能为空
13. indicatorNews[].parameters[].paramType: 不能为空, 必须是 "number", "string" 或 "boolean"

【交叉条件说明】
- crossover 时 operator 只能是 ">" 或 "<"
- ">" 表示上穿(前一周期 <= 被比较值, 当前 > 被比较值)
- "<" 表示下穿(前一周期 >= 被比较值, 当前 < 被比较值)

【止盈止损设置规则 - 重要】
1. 必须根据用户描述设置止盈止损值
2. 如果用户提到"止盈X%"，则 takeProfitRatio = X/100 (例如: 止盈10% → takeProfitRatio: 0.1)
3. 如果用户提到"止损X%"，则 stopLossRatio = X/100 (例如: 止损5% → stopLossRatio: 0.05)
4. 如果用户提到"严格控制止损"、"严格止损"等，必须设置合理的 stopLossRatio 值 (建议0.03-0.08)
7. 如果用户完全没有提及止盈止损相关内容，则为 null

【默认值规则】
- 用户未提及的参数使用默认值
- positionType 未提及默认 "both"
- buyFee/sellFee 未提及默认 0.001
- liquidationThreshold 未提及默认 90

【输出要求】
仅返回一段合法JSON, 不要任何注释或markdown代码块包裹
