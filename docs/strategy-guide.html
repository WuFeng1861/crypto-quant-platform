📈

指标 (Indicator)

定义价格数据的计算逻辑，如MA、RSI、MACD等。包含计算代码和参数定义，可被多个策略复用。

⚙️

策略 (Strategy)

组合多个指标，配置交易参数如手续费、止盈止损等。是完整的交易规则集合。

🎯

条件 (Condition)

定义触发交易的逻辑规则，如指标交叉、阈值比较等。决定何时买入或卖出。

📊

参数 (Parameter)

指标的可配置参数，如周期数、平滑系数等。使指标具有灵活性和可调优性。

Part 1

指标开发指南

学习如何创建自定义技术指标

指标JSON完整结构

indicator.json 
{
  "name": "MA",
  "description": "简单移动平均线指标",
  "calculationCode": "function calculate(priceData, parameters) { ... }",
  "parameters": [
    {
      "name": "period",
      "description": "计算周期",
      "paramType": "number",
      "defaultValue": "20"
    }
  ]
}

字段说明

字段名 类型 必填 说明
name string 必填 指标名称，建议使用大写英文，如 MA、RSI、MACD
description string 可选 指标描述，说明指标的用途和计算方式
calculationCode string 必填 计算函数代码，必须是有效的JavaScript函数
parameters array 可选 参数定义数组，定义指标的可配置参数
💡

命名规范

AI生成的指标名称必须以 "AI_" 开头，格式为 "AI_指标类型_参数"，例如：AI_MA_5、AI_RSI_14。描述必须包含 "[AI生成]" 前缀。

计算函数编写规范

函数签名（固定格式） 
function calculate(priceData, parameters) {
  // priceData: 价格数据数组
  // parameters: 参数对象，如 { period: 20 }
  
  // 返回计算结果数组
  return result;
}

priceData 数据结构

价格数据格式 
// priceData 是一个数组，每个元素包含：
[
  {
    timestamp: 1640995200000,    // 时间戳（毫秒）
    openPrice: 47000.50,         // 开盘价
    highPrice: 47500.00,         // 最高价
    lowPrice: 46800.00,          // 最低价
    closePrice: 47200.25,        // 收盘价
    volume: 1250.75              // 成交量
  },
  // ... 更多数据
]
⚠️

重要：使用 BigNumber 进行浮点运算

所有浮点运算必须使用 BigNumber 库，禁止直接使用 +、-、*、/ 运算符，以避免精度丢失问题。

完整示例：MA指标

MA计算代码 
function calculate(priceData, parameters) {
  const period = parameters.period || 20;
  const result = [];
  
  for (let i = 0; i < priceData.length; i++) {
    if (i < period - 1) {
      result.push(null);
    } else {
      let sum = new BigNumber(0);
      for (let j = 0; j < period; j++) {
        sum = sum.plus(new BigNumber(priceData[i - j].closePrice));
      }
      result.push(sum.dividedBy(period).toNumber());
    }
  }
  
  return result;
}

多轨指标示例：MACD

MACD返回对象数组

    {
      macd: 0.123,       // MACD线
      signal: 0.098,     // 信号线
      histogram: 0.025   // 柱状图
    },
    // ... 更多数据点
  ];
}

策略基础字段

字段名 类型 必填 默认值 说明
name string 必填 - 策略名称
description string 可选 - 策略描述
positionType enum 可选 both 持仓类型：long(做多) | short(做空) | both(双向)
buyFee number 可选 0.001 买入手续费率（0.001 = 0.1%）
sellFee number 可选 0.001 卖出手续费率（0.001 = 0.1%）
liquidationThreshold number 可选 90 强平阈值（百分比）
takeProfitRatio number 可选 null 止盈比例（0.15 = 15%）
stopLossRatio number 可选 null 止损比例（0.08 = 8%）
💡

止盈止损设置规则

• 用户提到"止盈X%"，则 takeProfitRatio = X/100（如：止盈10% → 0.1）
• 用户提到"止损X%"，则 stopLossRatio = X/100（如：止损5% → 0.05）
• 如果用户完全没有提及止盈止损，则为 null

indicatorNews - 新建指标定义

用于在策略中直接定义新指标，无需预先创建指标记录。

indicatorNews 结构 
"indicatorNews": [
  {
    "name": "AI_MA_5",
    "description": "[AI生成] 5日移动平均线",
    "code": "function calculate(priceData, parameters) { ... }",
    "parameters": [
      { "name": "period", "description": "计算周期", "paramType": "number", "defaultValue": "5" }
    ]
  }
]

indicators - 指标配置引用

通过索引引用 indicatorNews 中定义的指标，并设置具体参数值。

indicators 结构 
"indicators": [
  {
    "indicatorNewsIndex": 0,
    "parameters": [
      { "name": "period", "value": "5" }
    ]
  },
  {
    "indicatorNewsIndex": 1,
    "parameters": [
      { "name": "period", "value": "20" }
    ]
  }
]
字段名 类型 说明
indicatorNewsIndex number 指向 indicatorNews 数组的索引（从0开始）
parameters array 参数值配置数组
parameters[].name string 参数名称，需与指标定义中的参数名匹配
parameters[].value string 参数值（字符串格式）
Part 3

交易条件配置

定义买入和卖出信号触发规则

条件JSON完整结构

condition.json 
{
  "indicatorIndex": 0,
  "comparisonType": "indicator",
  "comparedIndicatorIndex": 1,
  "constantValue": "30",
  "currentValuePath": "",
  "comparedValuePath": "",
  "operator": ">",
  "conditionType": "crossover",
  "action": "buy",
  "group": 1,
  "priority": 1,
  "customCode": ""
}

字段详细说明

字段名 类型 必填 说明
indicatorIndex number 必填 指向 indicators 数组的索引
comparisonType enum 必填 constant(与常量比较) 或 indicator(与指标比较)
comparedIndicatorIndex number 条件性 当 comparisonType="indicator" 时必填
constantValue string 条件性 当 comparisonType="constant" 时必填
currentValuePath string 可选 从复杂对象提取值的路径，如 'macd'、'signal'
comparedValuePath string 可选 比较值的属性路径
operator enum 必填 > | >= | == | != | < | <=
conditionType enum 必填 value(数值比较) 或 crossover(穿越检测)
action enum 必填 buy | sell | none
group number 可选 条件分组，同组用AND逻辑，不同组用OR逻辑
priority number 可选 组内优先级，数字越小优先级越高
customCode string 可选 自定义代码逻辑

条件类型详解

📊 value - 数值比较
▼

当指标值满足比较条件时触发信号。

示例：RSI低于30买入 
{
  "indicatorIndex": 0,
  "comparisonType": "constant",
  "constantValue": "30",
  "operator": "<",
  "conditionType": "value",
  "action": "buy",
  "group": 1,
  "priority": 1
}

含义：当指标0的当前值 < 30 时，触发买入信号

📈 crossover - 穿越检测
▼

检测一条线是否穿越另一条线或常量。

ℹ️

穿越判断规则

operator=">"：上穿（前一周期 ≤ 被比较值，当前 > 被比较值）
operator="<"：下穿（前一周期 ≥ 被比较值，当前 < 被比较值）

示例：MA5上穿MA20买入 
{
  "indicatorIndex": 0,
  "comparisonType": "indicator",
  "comparedIndicatorIndex": 1,
  "operator": ">",
  "conditionType": "crossover",
  "action": "buy",
  "group": 1,
  "priority": 1
}

比较类型

🎯

constant - 与常量比较

将指标值与固定数值比较，如RSI与30/70比较。需要设置 constantValue 字段。

📊

indicator - 与指标比较

将两个指标值进行比较，如MA5与MA20比较。需要设置 comparedIndicatorIndex 字段。

买卖信号定义

📈 BUY

action: "buy"

条件满足时执行买入操作。适用于做多策略或双向策略的开仓信号。

📉 SELL

action: "sell"

条件满足时执行卖出操作。适用于做多策略的平仓或做空策略的开仓。

条件组合逻辑

ℹ️

分组规则

同组条件：使用 AND 逻辑，必须全部满足
不同组条件：使用 OR 逻辑，满足任一组即可

条件组合示例 
"conditions": [
  {
    "indicatorIndex": 0,
    "comparisonType": "indicator",
    "comparedIndicatorIndex": 1,
    "operator": ">",
    "conditionType": "crossover",
    "action": "buy",
    "group": 1,
    "priority": 1
  },
  {
    "indicatorIndex": 2,
    "comparisonType": "constant",
    "constantValue": "50",
    "operator": ">",
    "conditionType": "value",
    "action": "buy",
    "group": 1,
    "priority": 2
  }
]

解读：买入需要同时满足两个条件（同组group=1）：
1. 指标0上穿指标1
2. 指标2大于50

对于返回对象数组的指标（如MACD），需要使用 currentValuePath 和 comparedValuePath 指定比较的属性。

自定义代码条件 (customCode)

ℹ️

什么是自定义代码？

当标准条件无法满足复杂交易逻辑时，可以使用 customCode 字段编写JavaScript代码来实现自定义判断逻辑。代码在安全的沙箱环境中执行，必须返回boolean值。

可用上下文变量

变量名 类型 说明 示例
indicatorValues any[][] 所有指标的计算结果数组，二维数组结构 indicatorValues[0][index]
index number 当前K线索引位置 index 或 index - 1
priceData PriceData[] 完整的价格数据数组 priceData[index].closePrice
current PriceData 当前K线数据（快捷访问） current.closePrice
previous PriceData 前一根K线数据（快捷访问） previous.closePrice
BigNumber Class BigNumber类，用于高精度计算 new BigNumber(current.closePrice)
Math Object JavaScript Math对象 Math.abs(value)

可用辅助函数

函数名 参数 返回值 说明
average(arr) 数字数组 number 计算数组的平均值
standardDeviation(arr) 数字数组 number 计算数组的标准差
getHistoricalData(start, end) 起始索引, 结束索引 PriceData[] 获取指定范围的历史价格数据
getIndicatorHistoricalData(idx, start, end) 指标索引, 起始索引, 结束索引 any[] 获取指定范围的指标历史数据

PriceData 数据结构

current / previous 对象属性 
{
  timestamp: 1640995200000,    // 时间戳（毫秒）
  openPrice: 47000.50,         // 开盘价
  highPrice: 47500.00,         // 最高价
  lowPrice: 46800.00,          // 最低价
  closePrice: 47200.25,        // 收盘价
  volume: 1250.75              // 成交量
}
⚠️

重要规则

必须返回 boolean 值：自定义代码必须返回 true 或 false
超时限制：代码执行超时时间为 10 分钟
错误处理：代码执行失败时返回 false，不会中断回测

示例1：价格突破前高

当收盘价突破最近20根K线最高价时买入 
// 获取最近20根K线数据
const history = getHistoricalData(index - 20, index - 1);
if (!history || history.length < 20) return false;

// 找出最高价
const highestPrice = Math.max(...history.map(k => k.highPrice));

// 当前收盘价突破前高
return current.closePrice > highestPrice;

示例2：指标穿越判断

指标0上穿指标1的自定义实现 
// 获取当前和前一个指标值
const currentVal0 = indicatorValues[0][index];
const previousVal0 = indicatorValues[0][index - 1];
const currentVal1 = indicatorValues[1][index];
const previousVal1 = indicatorValues[1][index - 1];

// 检查是否有效
if (currentVal0 == null || previousVal0 == null || 
    currentVal1 == null || previousVal1 == null) {
  return false;
}

// 上穿判断：前一根 <= 被比较值，当前 > 被比较值
return previousVal0 <= previousVal1 && currentVal0 > currentVal1;

示例3：多条件组合

RSI低于30且价格在MA下方时买入 
// 获取RSI值（指标0）
const rsi = indicatorValues[0][index];
// 获取MA值（指标1）
const ma = indicatorValues[1][index];

if (rsi == null || ma == null) return false;

// RSI低于30且价格在MA下方
return rsi < 30 && current.closePrice < ma;

示例4：使用标准差判断波动

价格波动率放大时买入 
// 获取最近20根K线的收盘价
const history = getHistoricalData(index - 20, index);
if (!history || history.length < 20) return false;

const closePrices = history.map(k => k.closePrice);

// 计算标准差（波动率）
const stdDev = standardDeviation(closePrices);
const avgPrice = average(closePrices);

// 计算变异系数
const cv = stdDev / avgPrice;

// 当波动率超过5%时触发
return cv > 0.05;

示例5：使用BigNumber精确计算

精确计算价格变化百分比 
if (!previous) return false;

// 使用BigNumber进行精确计算
const currentPrice = new BigNumber(current.closePrice);
const prevPrice = new BigNumber(previous.closePrice);

// 计算涨跌幅
const changePercent = currentPrice.minus(prevPrice)
  .dividedBy(prevPrice)
  .multipliedBy(100)
  .toNumber();

// 涨幅超过3%时买入
return changePercent > 3;

最佳实践

• 始终检查数据有效性（null检查）
• 使用BigNumber处理价格计算，避免精度问题
• 代码尽量简洁，复杂逻辑可拆分为多个条件
• 利用辅助函数简化常见计算
• 测试时先用小数据集验证逻辑正确性

检查清单

必填字段检查

在提交策略前，请确保以下字段都已正确填写

📋 策略基础信息

  • name 策略名称不能为空
  • indicatorNews 指标定义数组不能为空
  • indicators 指标配置数组不能为空
  • conditions 条件数组不能为空

🎯 条件字段检查

  • indicatorIndex 不能为空
  • comparisonType 必须是 "indicator" 或 "constant"
  • operator 不能为空
  • conditionType 不能为空
  • action 必须是 "buy"、"sell" 或 "none"

📈 指标字段检查

  • indicatorNews[].name 指标名称不能为空
  • indicatorNews[].code 计算代码不能为空
  • parameters[].name 参数名不能为空
  • parameters[].paramType 必须是 "number"、"string" 或 "boolean"
