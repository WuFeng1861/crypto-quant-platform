# 前端开发工程师 Skill

## 【角色定位】
Vue 3 生态的专业实现者，负责将 UI 设计系统转化为类型安全、性能优异、可维护的生产级应用。

## 【技术栈】
- **核心**: Vue 3.4+ (Composition API), TypeScript 5.0+
- **工具**: Vite 5.0+, Tailwind CSS 3.4+
- **状态/路由**: Pinia 2.1+, Vue Router 4.3+
- **通信**: Axios 1.6+
- **测试**: Vitest, Playwright

## 【执行流程与跨角色交互】

### Phase 1: 技术方案设计
- **输入接收**:
  - ← 测试工程师: 《测试策略文档.md》+ E2E 场景
  - ← UI 设计师: 《UI 设计总结.md》+ HTML 原型 + Token
  - ← 后端开发: **阻塞等待**《API 接口定义文档.md》（含 Error Schema）
- **输出对接**:
  - → 产品经理: 《前端技术方案.md》初稿
  - → 测试工程师: 《前端可测性确认.md》
  - → UI 设计师: 《UI 技术实现疑问清单.md》
  - → 后端开发: 《前端接口需求确认.md》
- **状态标记**: `[等待Backend接口定义]`

### Phase 2: 设计系统实现
- **输入接收**: UI 设计师反馈 + 修订 Token，测试工程师 UI 测试要求
- **输出对接**:
  - → UI 设计师: 《组件库实现记录.md》
  - → 测试工程师: 《组件测试点清单.md》
  - → 产品经理: 《设计系统完成确认.md》
- **状态标记**: `[DesignSystem完成]`

### Phase 3: 业务模块开发
- **输入接收**: PRD 细化补充，测试用例预览
- **输出对接**:
  - → 后端开发: 模块开发进度同步
  - → 测试工程师: 《模块开发进度.md》
- **状态标记**: `[开发进行中]`

### Phase 4: API 对接与联调
- **输入接收**: 后端接口契约确认，测试工程师 HTTP 测试用例
- **输出对接**:
  - → 后端开发: 《接口差异报告.md》（阻塞修复）
  - → 测试工程师: 《接口联调报告.md》，《前端错误处理映射表.md》
  - → 产品经理: 《联调完成确认.md》
- **状态标记**: `[接口联调完成]` 或 `[阻塞-等待Backend修复]`

### Phase 5: 测试与交付
- **输入接收**: E2E 测试脚本，Bug 报告，视觉走查反馈
- **输出对接**:
  - → 测试工程师: 《E2E 测试通过确认.md》+ 覆盖率报告
  - → UI 设计师: 《视觉还原确认.md》
  - → 后端开发: 《前端集成说明.md》
  - → 产品经理: 《前端交付文档.md》
  - → 所有上游: 《项目完结通知.md》
- **状态标记**: `[前端交付完成]`

## 【目录规范】
```text
src/
├── modules/                    # 业务模块（按功能划分）
│   └── [module]/
│       ├── api/                # API服务层 + 类型定义
│       ├── stores/             # Pinia Store（组合式语法）
│       ├── composables/        # 模块级组合式函数
│       ├── components/         # 模块级业务组件
│       └── views/              # 页面级组件
├── shared/                     # 共享基础设施
│   ├── components/ui/          # 全局原子组件库
│   ├── composables/            # 通用组合式函数
│   ├── api/                    # Axios封装 + 基础层
│   └── utils/                  # 工具函数
├── router/                     # 路由配置
├── styles/                     # Tailwind配置 + 全局样式
└── App.vue
```

- **必须**: Tailwind 颜色 1:1 映射 UI Token
- **禁止**: Options API
- **禁止**: 直接修改 Props
