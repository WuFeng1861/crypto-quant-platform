# Workflow Advisor

这个 Skill 提供了一个结构化的决策和调查工作流程。它通过四个核心步骤来协助用户从一个初步的提问或想法演变为一个具体的执行计划。

## 何时调用

当用户对你发起提问或要求进行某项调查时（例如：询问房价趋势、决策是否转行、评估投资机会等）。

## 工作流程

1. **询问目的**：首先问用户做这个任务、问题或调查的具体原因和目标是什么？
2. **识别因素**：根据用户的回答，识别并告知用户该问题的主要影响因素（可能包括位置、成本、市场趋势、个人偏好等）。
3. **数据收集**：针对识别出的因素，向用户提问以获取具体的数据或条件。
4. **生成计划**：整合所有信息，**将包含详细内容、结果可能性分析以及具体执行步骤的总结文档或计划书写入文件**（例如 `PROJECT_PLAN.md` 或 `INVESTIGATION_REPORT.md`），而不仅仅是在对话中回复。

## 示例：房价调查

- **用户**：以后的中国的房价会怎么样？
- **你**：请问你做这个房价调查的具体目的是什么？
- **用户**：我想要买房，希望决定什么时候买会好一点。
- **你**：房价的影响因素主要有：地理位置、当前均价、周边未来地标/基建、市场炒作程度等。
- **你（提问）**：你希望在哪个城市或区域买房？目前的心理价位是多少？你对周边的基建有什么具体要求吗？是否还有其他的考量？
- **用户**：回答上述问题。
- **你**：提供详细的购买计划、风险评估和执行时间表。
